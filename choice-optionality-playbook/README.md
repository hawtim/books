# 普通上班族的选择权操作手册

> 不是教你炒股，而是帮助你在收入、资产、债务、职业风险与生活选择之间，建立一个不被单一工资绑死的人生系统。

**状态：v0.1 草稿**  
本项目是一份持续迭代的公开小册子。它记录一套面向普通上班族的思考框架：先保证生存，再建立流动性与长期资产，最后获得对工作、城市、关系和时间的更多主动权。

## 这份手册不是什么

- 不是荐股、喊单或短期交易策略。
- 不是“辞职就自由”的鸡汤。
- 不承诺收益，也不替任何人做投资、税务、法律或人生决策。
- 不把资产规模当作唯一尺度；选择权也取决于健康、家庭责任、技能、城市成本与风险承受能力。

## 它要解决的问题

很多人收入不低，却依然无法拒绝一份消耗性的工作；账面资产不少，却不敢停下来半年；买了很多理财产品，却从未计算过自己真正能撑多久。

这份手册尝试回答五个更底层的问题：

1. 什么是选择权？为什么高收入不等于自由？
2. 在开始追求收益前，怎样先建立最低生存系统？
3. 流动性、债务、固定支出如何共同决定职业退出权？
4. 投资怎样服务于长期选择，而不是变成新的焦虑来源？
5. 当资产、职业、地点与家庭彼此冲突时，怎样做更少后悔的决策？

## 使用方式

- 把这份项目当作一个框架，不是一份标准答案。
- 先建立自己的数据：支出、现金、债务、家庭责任、收入稳定性。
- 先解决最脆弱的一环，再讨论收益和优化。
- 每次重大决策都写下假设、可承受损失、触发条件与复盘日期。

## 版本原则

稳定的底层框架放在正文；会快速变化的市场、政策、产品和工具放在后续更新中。任何涉及具体规则或市场信息的内容，都应在行动前自行核验。
