# 03. 债务：它如何压缩职业退出权

> 债务不是原罪。真正危险的是：你用一份不稳定的收入，承担了一笔不能暂停的长期承诺。

## 1. 债务的核心不是利率，而是刚性

讨论债务时，人们容易只盯着利率：3% 是否便宜，5% 是否可以承受，信用贷是不是划算。

但对选择权而言，更重要的问题是：

- 每月是否必须还；
- 收入中断后是否仍要还；
- 债务是否会迫使你在低谷卖资产；
- 期限是否与你持有的资产期限匹配；
- 最坏情景下，你能否继续履约。

低利率债务不必然危险，高利率债务也不必然立刻致命。真正决定风险的，是债务与现金流、流动性和人生阶段之间的匹配程度。

## 2. 债务会放大两个问题

### 它放大现金流中断

没有债务时，失业意味着要降低支出；有债务时，失业意味着在支出之外还要完成固定偿还。你的最低生存成本因此被抬高，生存月数被压缩。

### 它放大资产回撤

当投资下跌、收入下降、债务到期同时发生时，你可能被迫在不利价格卖出资产，甚至借新债还旧债。此时，原本只是波动的市场风险，会变成真实的财务损失。

## 3. 用四个指标审视一笔债务

| 指标 | 要问的问题 | 风险信号 |
|---|---|---|
| 月供覆盖率 | 月供占稳定税后收入多少？ | 高度依赖单一工资 |
| 到期风险 | 本金何时到期？是否集中到期？ | 到期时需要一次性筹钱 |
| 利率风险 | 利率是否可能上升？是否高于你的可预期回报？ | 依赖不确定投资收益覆盖利息 |
| 抵押与追索 | 违约后会失去什么？ | 核心资产、信用或家庭关系被绑定 |

一个简单的原则是：不要用“平均市场收益”去承诺“确定性的还款义务”。市场可能长期向上，但你的债务账单不会等市场恢复。

## 4. 债务的三种角色

### 生产性债务

它有可能提高长期收入能力或降低必要成本，例如合理的教育投入、必要的居住安排、能提升工作能力的设备。

但“有可能”不等于必然。任何生产性债务都应有明确回报路径和退出方案。

### 消费性债务

它提前消费未来收入，却不增加生产能力或资产价值。高利率信用卡分期、频繁消费贷、为了维持面子而加杠杆，通常会直接吞噬选择权。

### 投机性债务

借钱押注高波动资产、以融资维持短线仓位、把未来现金流建立在“只要市场不跌”之上。这类债务最危险，因为它把生活系统绑定到无法控制的价格变化。

## 5. 对“低息杠杆”的边界

低息融资可能在资产配置中有合理位置，但前提很严格：

1. 你的生存缓冲不依赖被杠杆的资产；
2. 你能够在资产下跌 30%–50% 时仍正常还款；
3. 你知道本金到期时从哪里来；
4. 你没有把融资收益当作日常生活费；
5. 你有明确的减仓、偿还或展期触发条件。

没有这些条件，所谓“低息”只是让风险更慢地显现。

## 6. 先处理哪笔债

可以用这个顺序排优先级：

1. **高利率、短期限、逾期风险高的债务**；
2. **会影响住房、工作、家庭稳定的刚性债务**；
3. **与高波动资产绑定的融资**；
4. **利率低、期限长、现金流可覆盖的债务**。

注意：提前还低息债不一定永远最优。若提前还款会让你失去全部流动性，那么短期安全可能反而下降。关键是同时保留缓冲，而不是把所有现金都拿去“清债”。

## 7. 这一章的行动任务

给每一笔债务建立一张卡片：

```text
债务名称：
剩余本金：
利率与计息方式：
每月最低还款：
到期日：
提前还款成本：
抵押物 / 违约后果：
最坏情景下的偿还来源：
我准备在什么条件下减少或清偿：
```

只要有一项写不出来，这笔债务就还没有被真正管理。
