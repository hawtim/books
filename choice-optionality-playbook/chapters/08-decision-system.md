# 08. 决策系统：用记录、复盘与边界减少自我欺骗

> 好决策不保证好结果；但没有系统的决策，会让你把运气误认为能力，把情绪误认为判断。

## 1. 人最容易在不确定性里骗自己

当结果还没出现时，几乎所有判断都能找到理由。当结果出现后，人又容易用结果倒推自己当初是对的或错的。

这会产生两个问题：

- 市场上涨时，把偶然收益理解为可复制能力；
- 市场下跌或项目失败时，把合理但暂时不利的决策全部否定。

要避免这两种极端，关键是把“当时为什么这么做”留下来。

## 2. 决策不是观点，而是可检验的假设

一个可复盘的决策至少包括：

| 要素 | 说明 |
|---|---|
| 目标 | 我想解决什么问题？ |
| 假设 | 我相信什么会发生，依据是什么？ |
| 备选项 | 除了当前选择，还有哪些方案？ |
| 成本 | 时间、金钱、关系、机会成本分别是什么？ |
| 最坏结果 | 最坏可能损失多少？我能否承担？ |
| 触发条件 | 什么发生时要加码、减仓、暂停或退出？ |
| 复盘日期 | 到什么时间点检查假设是否仍成立？ |

如果一个决定只剩“我感觉会涨”“我觉得应该离职”“我相信这座城市适合我”，它可能是直觉，但还不是系统。

## 3. 区分可逆与不可逆决策

并非所有事情都值得同样长时间研究。

### 可逆决策

可以低成本试错、调整或撤回。例如：短期旅居、尝试写作、开一个小仓位、做一个产品原型、上一个课程。

它们应该快速、小规模地做，从反馈中学习。

### 不可逆或高摩擦决策

很难撤回、成本高、会影响他人。例如：高杠杆买房、结婚生育、移民、彻底离开行业、大额担保、长期照护承诺。

它们需要更长观察期、更充分信息、更高安全边际和更多情景推演。

一个常见错误是：对可逆决定过度拖延，对不可逆决定却因为情绪或外部压力仓促下注。

## 4. 用“前验—过程—后验”复盘

### 前验：做之前

写下你认为最可能发生什么、最坏会怎样、什么证据会推翻你的判断。

### 过程：进行中

记录新信息是否真的改变假设，还是只是引发情绪。不要因为每天都有新信息，就每天推翻系统。

### 后验：结果后

复盘时不要只问赚没赚、成功没成功，而要问：

- 原始假设是否成立？
- 我有没有遵守仓位与边界？
- 损失是正常波动、执行错误，还是认知错误？
- 哪些信息当初应该知道却忽略了？
- 这个经验是否能迁移到下一次？

## 5. 给自己设置反脆弱的规则

以下规则不保证你永远正确，但能防止一次错误毁掉系统：

- 不用生存资金进行高风险下注；
- 不因短期浮盈永久抬高生活成本；
- 不在极端情绪时做重大资产或关系决定；
- 重大决定至少隔夜，复杂决定至少跨一个周末；
- 每次加杠杆前，先写最坏情景；
- 主动记录反对意见，而不是只收藏支持自己的信息；
- 让一个不在局内的人读你的决策说明，看他能否复述你的逻辑。

最后一条尤其重要。你想做内容，本质上也是在训练这件事：能否让别人准确理解你，而不是替你二次整理。

## 6. 信息摄入也需要风险预算

过多信息并不自动带来更好判断。新闻、行情、社群观点、KOL 和群聊，会让人误以为自己在研究，实际只是增加噪音与冲动。

可以把信息分成三层：

| 层级 | 内容 | 使用方式 |
|---|---|---|
| 基础事实 | 财务数据、规则、合同、原始资料 | 重大决策必须回到这一层 |
| 高质量解释 | 研究、专业观点、历史案例 | 用于建立假设与反方观点 |
| 市场噪音 | 热点、短视频、群聊、情绪化预测 | 限时摄入，不作为关键依据 |

真正有价值的信息，不是让你更兴奋，而是让你更能排除错误路径。

## 7. 这一章的行动任务

从今天起，对一个重要决定写一页记录：

```text
我正在决定：
我想实现的目标：
我相信的关键假设：
替代方案：
最坏结果与可承受损失：
什么证据会让我改变想法：
下一次复盘日期：
```

不追求文笔。它的价值在于，让未来的你能看到今天的你到底是如何判断的。
